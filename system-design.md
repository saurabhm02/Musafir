Musafir Design System

1. Product

Musafir — Travel, Together

Musafir is a community-driven travel app focused on the journey, not only the destination. Users discover places along routes, save places and memories, track trips, and turn completed journeys into visual travel stories.

Core experience:

Discover → Plan → Travel → Remember → Share

The interface should feel like a premium travel product, not a generic SaaS dashboard or an AI-generated app.

4. Typography

Use a clean modern sans-serif.

Recommended:

Inter

SF Pro

Geist

Typography should be highly readable and confident.

Scale

Display: 36 / 40, bold

Heading 1: 30 / 36, bold

Heading 2: 24 / 30, semibold

Heading 3: 20 / 26, semibold

Body large: 17 / 24

Body: 15 / 22

Body small: 13 / 18

Use large typography for travel storytelling, not decorative effects.

5. Spacing

Use an 8px base system.

4, 8, 12, 16, 20, 24, 32, 40, 48, 64

Prefer generous whitespace.

Do not fill every available area with cards or information.

6. Radius

Keep corners restrained.

Small: 8px

Medium: 12px

Large: 16px

Extra large: 20px

Pills: 999px

Avoid making every component extremely rounded.

7. Shadows

Use very subtle shadows only when elevation is necessary.

Preferred:

0 4px 20px rgba(17,17,17,0.06)

Most UI should rely on whitespace and borders instead of heavy shadows.

8. Navigation

Home

Explore

Add

Trips

Profile

The Add action can be slightly emphasized.

Keep navigation quiet and consistent.

9. Screen Design

Onboarding should introduce the philosophy of Musafir rather than explain every feature.

Explore beautiful routes and discover hidden places along the way.

Use:

Full-width travel photography

Large editorial heading

Small progress indicator

Minimal next button

Screen 2

Places worth the detour

Discover food, viewpoints, cafés, temples, rest stops, and hidden places other travelers found.

Screen 3

Real places. Real photos.

Screen 4

22. Maps

Maps are a core part of Musafir.

Use a clean map style with muted terrain and roads.

The route should use the Musafir accent.

Markers should be:

Simple

Category-aware

Easy to scan

Not overly decorative

Use the 3D terrain treatment where it genuinely improves route discovery, but do not turn the entire UI into a 3D/glass interface.

23. Photography

Photography is a major visual element.

Use:

Large hero images

Real traveler photos

Rounded image corners

Editorial image grids

Minimal overlays

Avoid excessive filters and artificial-looking imagery.

24. Mascot

If the Musafir mascot is retained, use it minimally.

Good places:

Onboarding

Empty states

Small brand moments

Do not use the mascot on every screen.

25. Interaction Principles

One primary action per screen

Progressive disclosure

Bottom sheets for contextual information

Smooth map transitions

Clear hierarchy

Minimal animation

Fast feedback

No unnecessary decorative motion

Every interaction should support discovery, planning, traveling, or remembering.

26. Design Rule

When choosing between:

more decoration

and

more clarity

always choose clarity.

When choosing between:

more UI

and

more travel content

choose travel content.

Musafir should feel like a product made for people who love traveling, not a UI showcase.
